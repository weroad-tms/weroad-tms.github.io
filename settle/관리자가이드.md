# 운송료 마감정산 관리자 가이드

운송사가 웹에서 근무일·추가비용을 입력해 제출하면, 그 자료가 위로드 서버로 들어오고, 관리자 화면에서 검토·확정 후 품의 8건이 자동으로 만들어지는 구조입니다.

- 관리자 화면: https://weroad-tms.github.io/settle/admin.html
- 운송사 화면: https://weroad-tms.github.io/settle/
- 운송사용 가이드: https://weroad-tms.github.io/settle/guide.html
- 로그인: 위로드 관리자 계정 (아이디 `이상진`)

## 1. 전체 흐름

| 단계 | 누가 | 화면 | 시기 |
|---|---|---|---|
| ① 이번 달 기준값 세팅 → 배포 | 관리자 | 관리자 화면 | 월말~1일 |
| ② 근무일·주차비·과태료·추가내역 입력 → 제출 | 운송사(대산·창호·로운) | 운송사 화면 | 1일~5일 |
| ③ 상차금액 파일, 개별지입·사업소득자·위풀 입력 | 관리자 | 관리자 화면 | 1일~5일 |
| ④ 제출 검토 → 확정 / 반려 | 관리자 | 운송사 제출 탭 | 5일 이후 |
| ⑤ 품의 8건 복사 → flex 상신 | 관리자 | 품의 탭 | 확정 후 |

운송사 화면에는 상차금액·운송비율이 보이지 않습니다.

## 2. 관리자 화면 구성

- **맨 위 줄:** 정산월, 주유단가(VAT 포함), 제출 기한, **JSON 불러오기**, **백업 받기**, **로그아웃**
- **서비스 체크박스:** 스낵24 · 조식24 · 현대차 · 편의점상온 · 편의점저온 (여러 개 동시 선택 가능, **전체 선택**)
- **탭:** 품의 · 운송사 제출 · 자료·매핑 · 별도 항목
- **필터:** 소속(운송사), 본/광주, **+ 기사 추가**

## 3. 처음 한 번만 (10월 마감 시작)

1. 관리자 화면 로그인
2. 맨 위 오른쪽 **JSON 불러오기** → `마감정산_시작_26.10.json` 선택 → 확인
   - 기사 112명 기준정보와 로운 노선 단가만 들어 있고, 9월 숫자는 비어 있습니다.
3. **운송사 제출** 탭 → **운송사 계정** → 대산물류·창호통운·로운로지스 계정 만들기 → **저장**
   - 아이디는 영문 소문자, 비밀번호는 6자 이상
   - 운송사에는 운송사 화면 주소, 아이디·비밀번호, 운송사용 가이드 주소를 전달

### 운송사 계정 (2026-11-04 생성)

| 운송사 | 아이디 | 입력 범위 |
|---|---|---|
| 대산물류 | daesan | 본점·광주 기사별 근무일·주차비·과태료·비고, 긴급용차 |
| 창호통운 | changho | 본점·광주 기사별 근무일·주차비·과태료·비고, 긴급용차 |
| 로운로지스 | roun | 용차 실비, 간선 노선별 운행 횟수 |

- 초기 비밀번호는 운송사별 안내 메시지로만 전달 (이 문서에는 적지 않음). 운송사가 첫 로그인 후 직접 변경.
- 비밀번호 초기화·계정 추가: **운송사 제출** 탭 → **운송사 계정** → 해당 계정 **수정**

## 4. 매월 할 일

### 월말~1일 — 세팅·배포
1. 맨 위 줄에서 **정산월**, **주유단가**, **제출 기한**(매월 5일) 입력
   - 주유단가: 오피넷 경기 광주시 경유 1개월 평균, 소수 2자리, 모든 운송사 공통
2. **자료·매핑** 탭 → **영업일 (서비스별 · 근무일 일할 기준)** 입력
3. 기사 변동(신규·퇴사·단가 변경)은 해당 서비스 탭에서 수정 또는 **+ 기사 추가**
4. 주행거리(TMS km)·회차거리 입력 (위로드 연동 전까지 직접)
5. **운송사 제출** 탭 → **운송사에 자료 내려주기**

### 1일~5일 — 상진님 입력
6. **자료·매핑** 탭에 상차금액 자료 올리기
   - 편의점: 시너지 판매현황(거래처) — 거래처분류 편의점종합, cs담배·cspace 포함, 집계
   - 현대차 상온: 판매현황, H_ 담당 과세+면세(택배 제외)
   - 현대차 저온: 판매현황(실배송), 현대 담당
   - 매핑 안 된 담당은 기사로 연결하거나 '제외' 지정
7. 스낵·조식 상차금액 입력 (위로드 연동 전까지 직접)
8. 개별지입·사업소득자 입력
9. **별도 항목** 탭: 위풀·핫픽스 청구(인사팀 자료), 토요일배송 횟수

### 5일 이후 — 검토·상신
10. **운송사 제출** 탭 → **새로고침** → 운송사별 제출 내역 확인
    - **확정** / **반려** / **작성 중으로 되돌리기**
11. **품의** 탭 → 품의별 **제목 복사 · 금액 복사 · 본문 1·2 복사** → flex 붙여넣기
12. **백업 받기**로 그 달 자료 보관

## 5. 운송사가 입력하는 것

| 운송사 | 입력 항목 |
|---|---|
| 대산물류 · 창호통운 | 기사별 근무일, 주차비, 과태료, 비고 / 긴급용차 내역 |
| 로운로지스 | 용차 실비 내역 / 간선 노선별 운행 횟수 |

통행비는 하이패스 지급이라 제외. 과태료는 위펀이 기사에게 지급하므로 청구에 더함.

## 6. 계산 규칙

**기사 유형별**
- 실주행형: (주행거리×1.15 + 추가거리) ÷ 연비 × 주유단가 ÷ 1.1 + 기본급 + 수당 + 산재·고용보험분
- 고정유류비형: 기본급 + 고정유류비 + 수당
- 편의점형: (주행거리 + 회차거리 + 추가거리) ÷ 연비(1톤 7, 2.5톤 6) × 주유단가 ÷ 1.1 + 기본급
- 정액형 / 수기형(특이 건)

**공통**
- 근무일 < 영업일이면 기본급·고정유류비 일할
- 주차비·과태료는 청구에 가산
- 기사별 원단위 반올림 1회 (10원 올림 없음)
- 세액: 운송사는 품의(세금계산서) 단위 공급가액 10%, 원 미만 버림 / 개별지입은 기사별
- 사업소득자: 원천세 3% + 지방세(그 10%), 각각 10원 미만 버림

**상차금액**
- 편의점: 시너지 순매출액 ÷ 1.1, A/B 담당·상온/저온 합산, DY이완식 → 임현철
- 현대차 상온: H_ 담당 과세+면세(택배 제외) / 저온: 실배송 현대 담당 ÷ 1.1
- 스낵·조식: 위로드 기사별 상차량

## 7. 품의 8건

본점·광주 × 운송사(세금계산서 단위). 제목은 "26년 @월 ○○ 지급의 건"에서 연·월만 바뀜.

1. 편의점저온 사업소득자 급여 지급의 건
2. 편의점상온 개별지입 운송료 지급의 건
3. 로운로지스 운송료 지급의 건(편의점 지방간선)
4. 편의점저온 개별지입 운송료 지급의 건
5. 스낵24/조식24 대산물류 운송료 지급의 건
6. 스낵/편의점상온/현대차 창호통운 운송료 지급의 건
7. 편의점저온 창호통운 운송료 지급의 건
8. 편의점저온 대산물류 운송료 지급의 건

분류: 종사업장 = 광주 / 토요일배송 → 저온 / 긴급용차 → 스낵 / 로운 → 본점 / 제이에스 제외(위펀 품의) / 위풀·핫픽스는 별도 표시

## 8. 남은 작업

- 위로드 연동: 스낵·조식 상차량, 주행거리 자동 입력
- 전월 대비 증감 분해 방식 확정, 차트
- 관리자 비밀번호 변경 기능
