위로드 설치

크롬(또는 엣지)에 한 번 설치하면 위펀오피스를 열 때마다 위로드가 자동으로 붙어요. 북마크는 이제 안 눌러도 돼요.

⬇ 위로드 내려받기 (zip)
  1. 압축 풀기내려받은 weroad-extension.zip을 오른쪽 클릭 → 압축 풀기. weroad 폴더가 생기면 지우지 말고 그대로 두세요(예: 문서 폴더로 옮겨 두기).
  2. 확장 프로그램 화면 열기주소창에 chrome://extensions 입력 (엣지는 edge://extensions).
  3. 개발자 모드 켜기오른쪽 위(엣지는 왼쪽 아래) 개발자 모드 스위치를 켜요.
  4. 폴더 불러오기압축해제된 확장 프로그램을 로드합니다 → 1번의 weroad 폴더 선택.
  5. 위펀오피스 새로고침오른쪽 아래 위로드 버튼이 보이면 끝. 처음 한 번만 로그인하면 다음부터는 자동으로 붙어요.
  6. 바탕화면 아이콘 만들기weroad 폴더 안의 make-desktop-icon.bat을 더블클릭. 바탕화면과 시작 메뉴에 위로드 아이콘이 생겨요. 누르면 주소창 없는 위로드 전용 창으로 위펀오피스가 열리고 위로드가 붙어 있어요.
    파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행.
주소창 오른쪽 퍼즐 모양 → 위로드 📌 고정하면, 아이콘을 눌러 위로드 열기를 바로 할 수 있어요.

업데이트는?

따로 안 해도 돼요. 위로드 기능은 열 때마다 최신 버전을 받아 와요.

북마크는?

지워도 되고 그대로 둬도 돼요. 둘 다 같이 써도 문제없어요.
